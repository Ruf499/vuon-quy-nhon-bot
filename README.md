# Vuon Quy Nhon Telegram Mini App

A mobile-first Telegram Mini App UI for an English ↔ Vietnamese translator.

## Current version
- 3-step onboarding flow matching the provided reference style
- EN / VN UI switch
- Telegram WebApp SDK included
- Translator screen
- No backend/API yet

## Deploy
This project is static HTML/CSS/JS and can be deployed directly to Vercel, Cloudflare Pages, or GitHub Pages.

The translation API will be added after the UI is connected to Telegram.
